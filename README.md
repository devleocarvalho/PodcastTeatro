Desafio de Projeto DIO: Criando um Podcast com Ferramentas de IA
🎙️ Projeto "Ribalta Sonora"
Este repositório documenta a criação de um podcast do zero utilizando um ecossistema de ferramentas de Inteligência Artificial, como parte do Desafio de Projeto da DIO. O projeto, intitulado "Ribalta Sonora", tem como objetivo explorar temas do universo das artes cênicas, e seu episódio piloto debate a relevância do teatro na era do streaming.

Entendendo o Desafio
O objetivo deste desafio é aplicar os conceitos de IA generativa para criar um produto de mídia completo. Isso envolve a utilização de prompts bem elaborados para gerar cada etapa do processo criativo, desde a identidade visual até o roteiro e a narração, culminando em um arquivo de áudio finalizado.

✨ Tecnologias Utilizadas

💻 Etapas do Projeto
O podcast foi desenvolvido seguindo uma esteira de produção baseada em prompts:

Identidade Visual: O primeiro passo foi criar a capa do podcast. Um prompt detalhado foi fornecido à IA para gerar uma imagem no estilo art déco que representasse o conceito do "Ribalta Sonora".

Roteirização: Em seguida, foi desenvolvido o roteiro do episódio piloto: "Por que o Teatro Ainda Importa na Era do Streaming?". O processo foi iterativo, começando com uma versão inicial e passando por refinamentos de conteúdo, expansão de diálogo e ajustes de tom para chegar à versão final com aproximadamente 1000 palavras.

Geração de Áudio (TTS): O roteiro final foi utilizado na plataforma ElevenLabs para gerar as narrações dos dois apresentadores, Helena e Ésquilo, com vozes distintas e naturais.

Edição e Finalização: Os áudios gerados foram compilados em um software de edição (Capcut), onde foram mixados, receberam uma trilha sonora de abertura e encerramento, e foram finalizados no formato .mp3.

🤖 Prompts Utilizados
Abaixo estão alguns dos principais prompts que guiaram a criação deste projeto:

1. Prompt para a Capa (Arte Gráfica):

Capa de podcast, arte gráfica minimalista e elegante. Uma cortina de teatro de veludo vermelho escuro entreaberta no centro. Pela fresta da cortina, em vez de um palco, vaza uma luz dourada intensa que forma o padrão de uma onda sonora. O título "RIBALTA SONORA" aparece em destaque, com uma fonte serifada clássica e sofisticada, em cor de ouro envelhecido. O fundo é preto, criando um alto contraste. Estilo art déco, dramático e limpo.

2. Prompt para o Roteiro (Versão Inicial):

Crie um roteiro para o Episódio 01: "Por que o Teatro Ainda Importa na Era do Streaming?". Duas pessoas conversando, até 1000 palavras.

(Nota: O roteiro passou por vários prompts de refinamento, como "expanda o diálogo", "altere o nome do apresentador para Ésquilo" e "limite o texto para uma versão mais concisa".)
